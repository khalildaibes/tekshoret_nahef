# תקשורת נחף — מערכת ניהול החנות

מערכת אחת שמרכזת את כל העסק: לקוחות, תיקונים, מלאי, חשבוניות, חנות מוצרים, ספקים ועובדים.

## הפעלה

1. התקנה (פעם אחת):
   ```
   npm install
   ```
2. הפעלת המערכת:
   ```
   npm start
   ```
3. פתחו בדפדפן:  **http://localhost:4750**

לעצירת השרת: סגרו את חלון הטרמינל או הקישו `Ctrl + C`.

## איפה נשמרים הנתונים?

כל הנתונים נשמרים בקובץ אחד:  **`data/db.json`**
המערכת קוראת וכותבת אליו אוטומטית בכל הוספה / עריכה / מחיקה.
מומלץ ללחוץ מדי פעם על כפתור **"גיבוי"** בסרגל העליון כדי להוריד עותק.

## מה יש במערכת

- 📊 **לוח בקרה** — סטטיסטיקות, הכנסות, רווח, התראות מלאי
- 👥 **לקוחות** — כרטיס אישי, היסטוריית תיקונים ותשלומים
- 🔧 **תיקונים** — כרטיס תיקון, סטטוס, חלקים שהוחלפו, רווח אוטומטי
- 📦 **מלאי וחלקים** — כמויות, ספקים, עלות, התראת מלאי נמוך
- 🧾 **חשבוניות** — הפקה והדפסה, מעקב תשלומים
- 🛒 **חנות מוצרים** — אביזרים למכירה ישירה
- 🚚 **ספקים** ו-🧑‍🔧 **עובדים**
- 🔍 **חיפוש חכם** — "iPhone 13 screen" → זמינות, עלות, ספק, רווח

## פריסה ל-Vercel (העלאה לאינטרנט)

ב-Vercel אין דיסק קבוע, ולכן הקובץ `db.json` לא ניתן לכתיבה שם.
הפתרון: באתר המקוון הנתונים נשמרים **בדפדפן עצמו** (localStorage) — המערכת
מזהה זאת אוטומטית וממשיכה לעבוד במלואה (הוספה, עריכה, מחיקה).

### השלבים
1. התקינו את Vercel CLI והתחברו (פעם אחת):
   ```
   npm i -g vercel
   vercel login
   ```
2. פרסמו את תיקיית האתר בלבד:
   ```
   cd "F:\תקשורת נחף\public"
   vercel --prod
   ```
   ענו על השאלות (שם הפרויקט וכו') — בסיום תקבלו כתובת אתר חיה.
3. לעדכון האתר בעתיד — הריצו שוב `vercel --prod` מתוך תיקיית `public`.

> אפשר גם לפרוס דרך אתר Vercel: העלו את הפרויקט ל-GitHub, ובמסך הייבוא
> הגדירו **Root Directory = `public`**. קובץ `vercel.json` כבר מוכן.

## גיבוי ב-Google Drive

הדפדפן **לא יכול** למשוך אוטומטית קובץ מ-Google Drive (חסימת אבטחה CORS),
לכן השתמשו ב-Drive כמקום שמירת הגיבויים — באופן ידני:

- **גיבוי:** לחצו "גיבוי" → הקובץ יורד → העלו אותו ל-Google Drive.
- **שחזור:** הורידו את הקובץ מ-Google Drive למחשב → לחצו "שחזור" → בחרו אותו.

כך אפשר להעביר נתונים בין מחשבים / דפדפנים, או לשחזר אחרי ניקוי הדפדפן.
חשוב: באתר המקוון הנתונים נשמרים פר-דפדפן, לכן גבו עותק באופן קבוע.
